# Ridhhi Party Shop

Neighbourhood party and gift shop website for Kalyanpur, Kanpur. Visit, call, WhatsApp, and directions — no cart or checkout.

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

Shop facts live in `content/site.ts`. Leave phone, WhatsApp, street address, hours, and maps fields empty until they are real. Set `NEXT_PUBLIC_SITE_URL` in `.env.local` before production (see `.env.example`).
